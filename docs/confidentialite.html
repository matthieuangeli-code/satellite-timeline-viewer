Confidentialité

L’exploration et le téléchargement ne nécessitent aucun compte utilisateur. Voici ce que le parcours transmet et conserve.

Quand vous explorez une parcelle

L’adresse saisie et le point sélectionné sont transmis aux API publiques nécessaires : géocodage Géoplateforme / BAN, cadastre API Carto IGN, photographies IGN. Ces fournisseurs reçoivent également les informations techniques d’une requête Internet, notamment l’adresse IP. La bibliothèque cartographique est distribuée par un CDN ; la page d’accueil utilise les polices Google Fonts.

SiteHistory n’ajoute pas d’outil publicitaire ou de mesure d’audience dans cette version. La consultation ne demande pas d’inscription.

Quand vous préparez un dossier

La parcelle confirmée, l’adresse saisie, les résultats des sources et les fichiers HTML/PDF sont conservés côté serveur dans le stockage de l’application. Le terrain et son voisinage sont interrogés auprès des sources présentées dans le rapport.

Les dossiers restent accessibles pendant 24 heures. Les fichiers expirés sont supprimés à la prochaine purge, notamment lors d’une nouvelle activité ou d’une purge administrative. La suppression physique n’est pas promise à la seconde d’expiration : le serveur gratuit peut être en veille.

Paiement et reprise du téléchargement

Le parcours actuel utilise exclusivement Stripe TEST. Aucune vraie carte ne doit être utilisée. Les informations saisies sur Stripe sont traitées par Stripe ; SiteHistory ne stocke aucun numéro de carte bancaire. Les identifiants de commande et d’événement permettent la vérification serveur et empêchent les traitements en double.

Un jeton confidentiel permet de retrouver la commande sans compte. Il est conservé dans l’onglet et, si le navigateur l’autorise, dans son stockage local pendant au plus 24 heures. Cela permet de retrouver le dossier dans un autre onglet du même navigateur. Ce stockage ne contient pas de donnée de carte bancaire.

Les liens de téléchargement sont signés et valables 10 minutes. Ils peuvent être renouvelés dans le navigateur d’origine pendant la période d’accès au dossier. Ne partagez ni ces liens ni le jeton : le PDF ou le HTML téléchargé peut ensuite être partagé volontairement par vos soins.

Hébergement et données techniques

La vitrine publique est hébergée sur GitHub Pages. Le serveur de préparation est hébergé sur Render, avec une base persistante dédiée Neon, tous deux configurés en région Frankfurt pour ce pilote. Les fournisseurs appliquent leurs propres conditions et journaux techniques. La suppression des fichiers actifs n’implique pas une suppression instantanée de leurs éventuelles sauvegardes.

Le site ne garantit pas une résidence exclusive de tous les flux chez ces trois fournisseurs : les API publiques, polices, CDN et Stripe ont leurs propres infrastructures.
